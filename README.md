# FileDrop
通过热点，从手机向电脑传输文件。

##使用方法

### 手机端（Android）
1. 下载 `FileDrop_1.0.apk` 并安装
2. 打开 App
3. 开启手机 **个人热点**
4. 等待自动扫描到电脑 IP，或手动输入

### 电脑端（有Python运行环境）
1. 连接手机热点
2. 确保电脑已安装 Python 3 环境
3. 下载 `FileDrop_Desktop.py`
4. 在终端运行：
   ```bash
   python FileDrop_Desktop.py
   ```
